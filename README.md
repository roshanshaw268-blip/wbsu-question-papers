# WBSU Question Papers Premium

Frontend for a WBSU question-paper website with:
- Subject/year search
- User login
- Premium plans: ₹20 / ₹100 / ₹150
- Premium dashboard
- Supabase database foundation

## Setup
1. Create a Supabase project.
2. Run `supabase.sql` in SQL Editor.
3. Replace `YOUR_SUPABASE_URL` and `YOUR_SUPABASE_PUBLISHABLE_KEY` in the HTML files.
4. Deploy the files to Netlify/Vercel.

## Important
Payment is intentionally not faked. Connect a real payment gateway on a secure server function before accepting payments. Never put secret payment keys in browser code.
